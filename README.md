# 명함첩

명함 사진을 찍으면 이름·기관·전화번호를 읽어서 기관별로 정리해 주는 아이폰 홈 화면 앱이에요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 화면 전체 (GitHub Pages 에 올림) |
| `server/Code.gs` | 구글 Apps Script 서버: 명함 읽기, 구글 시트·드라이브 저장 |
| `manifest.webmanifest`, `sw.js`, `icon-*.png` | 홈 화면 앱 설정·아이콘 |
| `version.txt` | 새 버전 자동 반영용 숫자 (`bump_version.py` 가 올림) |

## 서버 만들기 (처음 한 번)

1. script.google.com → 새 프로젝트 → `server/Code.gs` 내용을 붙여 넣고 저장
2. 함수 `setup` 실행 → 권한 허용 (구글 시트 '명함첩', 드라이브 폴더 '명함첩 사진'이 만들어져요)
3. 배포 → 새 배포 → 웹 앱 / 실행: 나 / 액세스: 모든 사용자 → `/exec` 주소 복사
4. `setup` 을 한 번 더 실행 → 실행 기록에 나온 **연결 암호** 확인
5. (권장) 프로젝트 설정 → 스크립트 속성 → `ANTHROPIC_API_KEY` 추가 → AI 가 명함을 읽어요 (한 장에 약 20~30원).
   넣지 않으면 구글 드라이브 글자 인식(무료)으로 읽고, 정확도는 조금 낮아요.
6. 앱 → 설정 → 서버 주소·연결 암호 넣고 '연결하기'

서버 코드를 고치면: 배포 → 배포 관리 → 연필 → 버전 '새 버전' → 배포 (주소는 그대로).

## 분류

중앙부처 · 소속·산하기관 · 지자체 · 공공기관 · 기업 · 사내(올포랜드) · 기타.
자동으로 읽은 명함은 노란 '확인 필요'로 표시되고, 열어서 '맞아요'를 누르거나 고치면 사라져요.
